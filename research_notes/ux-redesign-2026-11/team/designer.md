# Designer (visual / system) — round 1

## 1. Five biggest vibe-coded tells
1. **Three competing voices in one screen: serif display, mono-caps labels, system sans.** Study back (`04b-study-back-grade-buttons.png`): "FRENCH / WORD / SAY IT / MEANS · NOUN / IN USE" mono caps stacked on every row, 7 labels for 1 word. The labels outweigh the content. `constants/theme.ts` `fonts.mono/monoBold`, `StudyCard.tsx`. Same on `03a` ("WHERE / WHEN"), `08a` ("LEARNING LANGUAGE").
2. **Pink is a surface, not an accent.** `02a-home-top.png`, `05a-calendar-month.png`: the rose header band, the rose floating tab bar and the rose-on-rose "this week" card all compete; nothing is the single hero. `colors.blush/skyDeep`, `HomeHeader.tsx`, `app/(tabs)/_layout.tsx:81-100`.
3. **Four tabs, four different page skeletons.** Home = band + framed wall; Calendar = band + title "The long view" + segmented pill; Scan = bare cream, no title; Boards = bare cream with a floating gear clipped into the status bar (`07a`, gear overlapping the clock/battery). No shared header, so it reads as four prototypes.
4. **Depth and radius are unprincipled.** Radii of 6/10/16/22/28/30/999 mixed (`StudyCard.tsx:1375` is a literal 28; theme has 22 and 30); grade buttons (`04b`) mix filled-red, outlined-sand, outlined-mint, filled-green, so Hard and Good look "disabled". Card has a flat bottom edge cut off above the footer (`04b`, `03a`): the white card ends in a hard rectangle, not a rounded one.
5. **Empty/dead space and half-finished chrome.** `03a` front of card: huge blank white below the sticker, sticker left-aligned not centred, dashed "Add what happened" box competes with the question. `06a` consent screen floats mid-void with the tab bar over "Privacy policy". `02a` the chip row is clipped mid-word ("A|") and then a sort control jammed beside it. `07a` Boards shows a big empty state AND a duplicate "+ New" tile.

## 2. Proposal

**Grid/spacing.** 4-pt base; scale 4/8/12/16/24/32/48 (existing, drop the odd `sm-2`). Screen gutter 20 everywhere (today 16-24 mixed). Card inner padding 16 (lists) or 20 (study/detail). Section gap 24.
**Radii (3 only):** 12 (inputs, chips-rect, thumbs), 20 (cards, sheets top), 999 (buttons, chips, tab bar). Delete 6/10/22/28/30.
**Type (UI face = Figtree, whole chrome).** Drop Newsreader and JetBrains Mono entirely: two families in the app, Klee One/Iansui (the learner's language) and Figtree (everything else). Figtree has real tabular figures for intervals/dates (`fontVariant: ['tabular-nums']`). Scale: Title 28/34 SemiBold; Heading 20/26 SemiBold; Body 16/24 Regular; UI 15/20 Medium (buttons, rows); Caption 13/18 Regular; Overline 12/16 SemiBold uppercase +0.6 tracking, only for the 3 section headers per screen that need it (kill the per-field mono labels in study; label a field only when it is ambiguous). Headword 40 in Klee. Minimum text size 12. Needs expo-google-fonts Figtree (already in the studied plan): **JS-only if font is already bundled, otherwise native rebuild** (fonts via config plugin in a new build; check `app.json`). IPA must be cmap-checked in Figtree before swap; fallback is Figtree body + system.
**Elevation (Depth 2, 3 steps).** E0 flat (page); E1 hairline 1px `border` + shadow 0 1 2 @6%, resting cards; E2 0 4 16 @10% tinted `rgb(36,64,107)`, floating (tab bar, FAB, sheets, current card); no shadow on buttons. Dark mode: shadows off, elevation by surface lightness (4 steps below).
**Motion/haptics.** Spring 220ms/damping 20 for sheets and press-scale (0.97); crossfade 150ms for tab content; card flip 280ms; haptics: selection on chips/tabs, light impact on reveal, success notification on Easy/saved sticker, warning on Again. All JS-only (reanimated, expo-haptics already present).
**Icons.** Keep the lucide set; one stroke 1.75, size 22 in bars / 20 in rows / 16 inline; no filled+outline mixes; tab icons get labels (11/Medium) under them (accessibility and discoverability).
**Components.** Button: 52h, radius 999, primary = peach fill + navy ink, secondary = card fill + 1px navy@16% border + navy text, tertiary = text-only actionText. One primary per screen. Chip: 36h, radius 999, selected = navy fill/white text (not peach: peach is for the one action). Sheet: radius 20 top, grabber 36x4 (lesson 8), scrim navy@40%. Tab bar: **not a floating pink pill**: a full-width card-colour bar, 56h + safe area, hairline top border, E2 shadow; active = navy icon + label + 3px peach underline dot; Scan is the centre item as a 48px peach circle raised 8px. Native-feeling, stops covering content (today it overlaps the list, `02a`).
**Shared page skeleton for all 4 tabs:** top row (safe area + 8): left = screen title Title 28 (Collection / Calendar / Scan / Boards), right = 40px profile avatar button (replaces the scattered gear). Header is page colour, not a coloured band; pageTop gradient #E4F0FB→#F8FBFF over the first 240px only.

## 3. Powder, not Rose
Argument: (a) The product's content is photographs of real things, many warm (croissant, cat, teapot in `ss4`). Warm-on-cool is complementary: cutouts pop on white/blue; on Rose, pink page + pink band + warm photo turns muddy (`ss4` vs `02a`). (b) Rose's whole story is "cozy", which the owner rejected as a physical metaphor; Powder is neutral and lets customisation carry personality. (c) A tool a serious learner trusts (Anki's own pull is calm and legible); navy ink gives 10:1 headings where Rose's rose-brown is 7:1 but reads as decoration. (d) Peach is rare: one hue for one job (the action) makes hierarchy automatic, which is exactly what Rose lacks. (e) It matches the app icon. Cost: peach fill is only 1.98:1 against the page, so the button is identified by its navy label (5.06:1) and fill, and I never use peach as text on light (use `actionText`).

- **UX/interaction role:** will want to keep tab labels hidden/floating bar for the Scan emphasis; I say labelled full-width bar.
- **Brand/delight:** may defend the Rose cosiness and the wall hero; I say the wall is a Boards feature, not the front page.
- **Learning/SRS role:** will want more info on the study card (stats, leech flags); I cap at word, IPA, meaning, example, one line of metadata.
- **Engineering:** font swap and tab-bar replacement touch the most files; tab bar and fonts may need a native build if Figtree isn't already embedded; everything else here is JS-only.
